# Basic HTML Website

A basic multi-page HTML website built as a practice project based on the [roadmap.sh Basic HTML Website project](https://roadmap.sh/projects/basic-html-website).

## Pages

* Home
* Projects
* Articles
* Contact

## Technologies

* HTML5

## What I Practiced

* Semantic HTML
* Multi-page website structure
* HTML forms
* Navigation between pages
* SEO meta tags
* HTML elements and attributes
* Basic accessibility practices

## Project Structure

```text
Basic-HTML-Website/
├── index.html
├── projects.html
├── articles.html
├── contact.html
├── images/
└── README.md
```

## Purpose

This project was created to practice the fundamentals of HTML and build a structured multi-page website without using CSS or JavaScript.
