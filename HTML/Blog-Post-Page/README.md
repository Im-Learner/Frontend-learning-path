# Blog Post Page

A multi-page blog website built with **HTML5** as part of my frontend development learning journey.

Project page: [roadmap.sh – Blog Post Page](https://roadmap.sh/projects/blog-post-page)

## Pages

| Page | Description |
|---|---|
| Home | Homepage with an introduction and featured content. |
| About | Information about the author and the website. |
| Blog | Blog archive with article listings. |
| Blog Post | An article about AI and the future of programming. |
| Contact | Contact page with an HTML form. |

## Technologies

- HTML5
- Semantic HTML

## Concepts Practiced

- HTML document structure and metadata
- Semantic elements such as `header`, `nav`, `main`, `article`, `section`, and `footer`
- Heading hierarchy and text formatting
- Ordered and unordered lists
- Links and multi-page navigation
- Images, `alt` attributes, `figure`, and `figcaption`
- Tables and content organization
- HTML forms and input elements
- Dates using the `time` element
- Code examples using `pre` and `code`
- Quotations using `blockquote` and `cite`
- Basic accessibility
- HTML validation
