# Contact Form

A simple HTML contact form project built as part of the [Frontend Developer Roadmap](https://roadmap.sh/projects/contact-form).

## Features
- Full name and email inputs
- Subject selection dropdown
- Message textarea with validation
- Radio buttons for referral source
- Optional checkbox
- HTML form validation
