# Pricing Comparison Table

This project was created as part of my HTML learning journey and focuses on building a semantic and accessible comparison table using HTML.

A simple HTML project that compares three fictional life plans: **The Dreamer**, **The Mogul**, and **The Sage**.

## Project

This project is based on the [Pricing Comparison Table](https://roadmap.sh/projects/pricing-comparison-table) challenge from roadmap.sh.

The original idea of pricing plans was adapted into a creative "Life Plans" theme to make the project more personal and engaging.

## Features

- Semantic HTML structure
- Comparison table using `<table>`, `<thead>`, `<tbody>`, and `<tfoot>`
- Accessible table headers using `scope`
- Use of `colspan` for shared table information
- Table caption using `<caption>`
- Navigation links
- Contact link using `mailto`
- Open Sans font using Google Fonts

## Technologies

- HTML5
- CSS3
- Google Fonts

## Purpose

The main purpose of this project was to practice HTML structure, semantic elements, tables, accessibility, and basic CSS while following the roadmap.sh learning path.
