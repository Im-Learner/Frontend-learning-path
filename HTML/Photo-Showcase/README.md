# Photo Showcase

An HTML photo showcase featuring Iran’s historical landmarks and natural wonders, built as part of my [roadmap.sh](https://roadmap.sh/projects/photo-showcase) frontend development learning journey.

## Features

- A collection of photographs showcasing Iran’s historical and natural attractions.
- Descriptive `alt` text for images to improve accessibility.
- Semantic image captions using `<figure>` and `<figcaption>`.
- A decorative image with an empty `alt` attribute.
- A locally hosted video with playback controls, a poster image, and English and Persian subtitles.
- An embedded YouTube travel documentary about Iran.
- Semantic HTML structure using `<header>`, `<main>`, `<section>`, and `<footer>`.
